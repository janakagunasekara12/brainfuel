Excel Basics for Beginners

Everything you need to know to get started with Microsoft Excel — the world's most widely used spreadsheet program.

⏱ 8 min read 📅 Updated 2024 👤 BrainFuel Team

What is Microsoft Excel?

Microsoft Excel is a spreadsheet program — a tool that lets you organise, calculate, and analyse data using a grid of rows and columns. It is used by students, teachers, accountants, business owners, and millions of everyday people around the world.

Think of Excel as a very powerful, smart table. Instead of just storing data, it can add it up, sort it, draw graphs from it, and much more — automatically.

💡
Did you know?

Microsoft Excel is used by over 750 million people worldwide and is one of the most in-demand skills in the job market.

Opening Excel and the Interface

When you open Excel, you will see the main screen — called the workbook. Let's learn the key parts:

PartWhat it does
RibbonThe menu bar at the top. Contains tabs like Home, Insert, Formulas, etc.
Formula BarThe long bar just below the ribbon. Shows what is inside the selected cell.
Name BoxShows the address of the currently selected cell (e.g. A1).
Spreadsheet gridThe main area made of columns (A, B, C…) and rows (1, 2, 3…).
Sheet tabsAt the bottom. You can have multiple sheets in one file.

Cells, Rows, and Columns

The grid is made up of cells. Every cell has a unique address (called a cell reference) made from its column letter and row number.

  • Columns run vertically and are labelled with letters: A, B, C, D…
  • Rows run horizontally and are labelled with numbers: 1, 2, 3, 4…
  • Cell A1 is the cell at column A, row 1 — the top-left corner of the sheet.
  • Cell B3 is column B, row 3.
📌
Key concept: Cell Reference

A cell reference is simply the column letter + row number. For example: C5 means column C, row 5. You will use cell references constantly in formulas.

Entering and Editing Data

Entering data in Excel is straightforward:

Click on a cell

Click any cell to select it. The selected cell gets a blue border and its address appears in the Name Box.

Type your data

Just start typing. You can enter text, numbers, or dates. You will see what you type appear in both the cell and the Formula Bar.

Confirm your entry

Press Enter to confirm and move to the next row. Press Tab to confirm and move to the next column. Press Escape to cancel.

Edit a cell

To change what is already in a cell, double-click it or press F2 on your keyboard. Then make your changes and press Enter.

Navigating the Spreadsheet

Here are the most useful keyboard shortcuts for moving around quickly:

KeyAction
Arrow keysMove one cell in any direction
Ctrl + HomeJump to cell A1 (top-left)
Ctrl + EndJump to the last cell with data
Ctrl + ArrowJump to the last filled cell in that direction
Page Up / DownMove one screen up or down

Basic Formatting

Formatting makes your spreadsheet easier to read. All formatting tools are in the Home tab on the ribbon.

Text Formatting

  • Bold – Press Ctrl + B or click the B button
  • Italic – Press Ctrl + I
  • Underline – Press Ctrl + U
  • Font size – Click the font size box and type a number (e.g. 14)
  • Font colour – Click the A with the colour bar and choose a colour

Cell Background Colour

To add a background colour to a cell (great for headers), select the cell and click the paint bucket icon in the Home tab. Choose any colour you like.

Adjusting Column Width

If your text is cut off, the column is too narrow. Fix it by:

  • Hovering over the border between two column letters (e.g. between A and B) until you see a double arrow
  • Then drag to make the column wider
  • Or double-click the border to auto-fit the column to its content
💡
Pro tip: Format as Table

Select your data and press Ctrl + T to instantly turn it into a formatted table with colours, filters, and auto-sizing. This is one of the best features for beginners!

Saving Your Work

Always save your work regularly. Excel files are saved with the .xlsx extension.

  • Save: Press Ctrl + S (or File > Save)
  • Save As: Press F12 to save with a new name or location
  • AutoSave: If you use Microsoft 365, turn on AutoSave in the top-left corner to save automatically to OneDrive
⚠️
Important:

Get into the habit of pressing Ctrl + S every few minutes. Power cuts and crashes happen — saved data is safe data.

Summary

Congratulations — you have just learned the foundations of Microsoft Excel! Here is a quick recap:

  • Excel is a spreadsheet program for organising and calculating data
  • The grid is made of columns (A, B, C…) and rows (1, 2, 3…)
  • Each cell has a unique cell reference like A1 or C5
  • Click a cell and type to enter data; press Enter to confirm
  • Use the Home tab to format text, colours, and column widths
  • Save your work with Ctrl + S
