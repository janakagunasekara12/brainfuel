Essential Excel Formulas

Unlock the real power of Excel. Learn the formulas that professionals use every day — explained clearly with examples you can follow.

⏱ 12 min read 📅 Updated 2024 👤 BrainFuel Team

What is a Formula?

A formula in Excel is an instruction that tells Excel to calculate something. Every formula starts with an equals sign (=). When you type = in a cell, Excel knows you are writing a formula, not just text.

For example, typing =2+2 in a cell will display 4. Typing =A1+B1 will add the values in cells A1 and B1 together.

📌
Golden rule of formulas

Always start a formula with =. Without it, Excel treats your entry as plain text and will not calculate anything.

Basic Arithmetic

Excel uses these symbols for arithmetic:

SymbolOperationExampleResult
+Addition=10+515
-Subtraction=10-55
*Multiplication=10*550
/Division=10/52
^Power (exponent)=2^38

You can also mix cell references: =A1*B1 will multiply whatever numbers are in those cells.

SUM – Add Numbers Quickly

The SUM function adds up a range of numbers. It is the most used function in all of Excel.

Syntax
=SUM(number1, number2, …)

Example: You have sales figures in cells B2 to B8. To get the total:

Formula
=SUM(B2:B8)

The colon : means "from B2 to B8" — all cells in that range. You can also SUM individual cells: =SUM(B2, B5, B9)

💡
AutoSum shortcut

Click on an empty cell below a column of numbers, then press Alt + =. Excel will automatically write a SUM formula for the numbers above — press Enter to confirm!

AVERAGE – Find the Mean

The AVERAGE function adds all numbers in a range and divides by how many there are.

Syntax
=AVERAGE(range)

Example: Average exam score for students in C2:C30:

Formula
=AVERAGE(C2:C30)

COUNT and COUNTA

COUNT counts how many cells in a range contain numbers. COUNTA counts cells that contain anything (numbers, text, dates).

Count numbers only
=COUNT(A1:A100)
Count all non-empty cells
=COUNTA(A1:A100)

MIN and MAX

Find the smallest or largest value in a range instantly.

Lowest value
=MIN(D2:D50)
Highest value
=MAX(D2:D50)

IF – Make Decisions

The IF function is one of the most powerful tools in Excel. It checks a condition and returns one value if the condition is true, and another if it is false.

Syntax
=IF(condition, value_if_true, value_if_false)

Example: You want to show "Pass" if a student's score (in cell C2) is 50 or above, and "Fail" if it is below 50:

Formula
=IF(C2>=50, "Pass", "Fail")
📌
Text in formulas needs quotes

When you want a formula to return text (like "Pass" or "Fail"), always wrap the text in double quotation marks. Numbers do not need quotes.

You can use comparison operators in the condition:

OperatorMeaningExample
=Equal toA1=100
>Greater thanA1>50
<Less thanA1<50
>=Greater or equalA1>=50
<=Less or equalA1<=50
<>Not equal toA1<>0

VLOOKUP – Look Up Values

VLOOKUP searches a column for a value and returns something from the same row in another column. It is perfect for looking up a product price from a table, finding a student's grade, and much more.

Syntax
=VLOOKUP(lookup_value, table_range, col_index, [FALSE])

The four parts:

lookup_value

What you are searching for. Example: a product name in cell A2.

table_range

The table where data lives. Example: E1:G100. The first column of this range must contain the values you are searching for.

col_index

Which column number (from the start of your table range) holds the answer you want. If the price is in the 3rd column of your table, enter 3.

[FALSE]

Always type FALSE (or 0) here. This means Excel looks for an exact match. Without FALSE, you can get incorrect results.

Example: You have a product list in columns E–G (Name, Category, Price). You want the price for the product named in A2:

Formula
=VLOOKUP(A2, E:G, 3, FALSE)
💡
Always use FALSE in VLOOKUP

The last argument in VLOOKUP should almost always be FALSE (exact match). Using TRUE (approximate match) requires your data to be sorted and often gives unexpected results.

Copying Formulas Down a Column

One of Excel's great features is that you can write a formula once and copy it to a whole column:

Write your formula in the first row

For example, type =SUM(B2:D2) in cell E2.

Select that cell

Click on E2 to select it.

Copy the formula down

Hover over the small square in the bottom-right corner of the cell (called the fill handle). When the cursor turns into a +, drag it down to copy the formula to as many rows as you need.

Excel will automatically adjust the row numbers for each row (B3:D3 for row 3, B4:D4 for row 4, and so on).

Summary

You now know the core Excel formulas used by millions of professionals every day:

  • SUM – adds up numbers in a range
  • AVERAGE – calculates the mean
  • COUNT / COUNTA – counts cells
  • MIN / MAX – finds smallest / largest value
  • IF – makes decisions based on a condition
  • VLOOKUP – looks up values in a table
