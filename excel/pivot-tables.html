Excel Pivot Tables Guide

Pivot Tables are Excel's most powerful feature for analysing data — and they are much easier than they look. No formulas needed.

⏱ 11 min read📅 Updated 2024👤 BrainFuel Team

What is a Pivot Table?

A Pivot Table is a special tool that lets you instantly summarise large amounts of data by reorganising it in different ways — without changing your original data and without writing any formulas.

Imagine you have a spreadsheet with 1,000 rows of sales transactions. With a Pivot Table, you can answer questions like:

  • What were total sales per region?
  • Which product sold the most?
  • How did each salesperson perform each month?

And you can answer them all within seconds, just by dragging and dropping fields.

💡
Why learn Pivot Tables?

Pivot Tables are consistently listed as one of the top Excel skills employers want. If you can use Pivot Tables, you stand out in any office job.

Before You Begin: Prepare Your Data

Pivot Tables work best with data that is set up correctly. Follow these rules:

  • Headers in row 1: Every column must have a heading (e.g. Date, Product, Region, Sales)
  • No empty rows or columns in the middle of your data
  • No merged cells — each cell should contain only one value
  • Consistent data types: All values in a column should be the same type (all numbers, or all dates, etc.)
📌
Format as Table first

Before creating a Pivot Table, select your data and press Ctrl + T to format it as a Table. This makes your Pivot Table automatically update when you add new rows — a huge time-saver.

Creating Your First Pivot Table

Select your data

Click anywhere inside your data table. You do not need to select all of it — Excel will detect the data range automatically.

Open the Insert tab

Click the Insert tab at the top of the screen.

Click PivotTable

Click the PivotTable button on the left side of the ribbon. A dialog box will open.

Choose where to place it

In the dialog box, you can put the Pivot Table on a New Worksheet (recommended — keeps things tidy) or on the existing sheet. Click OK.

The Pivot Table panel opens

A blank Pivot Table area appears on the left, and the PivotTable Fields panel appears on the right. This is where you build your analysis.

Understanding the PivotTable Fields Panel

The PivotTable Fields panel has two sections:

  • Field list (top): All the column headers from your data (e.g. Date, Product, Region, Sales)
  • Four areas (bottom): Filters, Columns, Rows, and Values — these control how the table is laid out
AreaWhat it does
RowsItems listed down the left side of the table (e.g. products, regions)
ColumnsItems spread across the top of the table (e.g. months, years)
ValuesThe numbers you want to calculate (e.g. SUM of Sales)
FiltersAdds a dropdown filter above the table to show/hide specific items

Building Your Analysis

Example: You want to see total sales by region. Here is how:

Drag "Region" to the Rows area

In the field list, find "Region" and drag it down to the Rows box. The Pivot Table will now list each region on the left side.

Drag "Sales" to the Values area

Find "Sales" in the field list and drag it to the Values box. The table will instantly calculate the total sales for each region.

See your results

The Pivot Table now shows the sum of sales for every region — built from all 1,000 rows of your raw data, in just two drag-and-drop moves!

Changing the Calculation Type

By default, Excel uses SUM in the Values area. You can change it to COUNT, AVERAGE, MAX, MIN, and more:

  • In the Values area of the field panel, click the dropdown arrow next to your value field
  • Click Value Field Settings
  • Choose a different calculation type from the list
  • Click OK

Refreshing When Data Changes

If you add or change data in your original spreadsheet, the Pivot Table does not update automatically (unless you used a Table as your source). To refresh:

  • Click anywhere inside the Pivot Table
  • Right-click and choose Refresh
  • Or press Alt + F5

Adding a PivotChart

You can create a chart directly from a Pivot Table — called a PivotChart. It updates automatically when you change the Pivot Table.

  • Click anywhere in the Pivot Table
  • Go to Insert tab and click PivotChart
  • Choose your chart type and click OK
  • The chart will appear and is linked to your Pivot Table data
💡
Add Slicers for interactive filtering

With the Pivot Table selected, go to Insert > Slicer. Choose a field (e.g. Region). A visual filter panel appears — click any region button to filter your entire Pivot Table instantly. Slicers are perfect for reports and dashboards.

Summary

You have now completed all four Excel lessons! Here is what Pivot Tables can do:

  • Summarise thousands of rows of data in seconds
  • Show totals, averages, counts — all without formulas
  • Slice and filter data interactively
  • Update automatically when linked to a Table
  • Generate PivotCharts for instant visuals
